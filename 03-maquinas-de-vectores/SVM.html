4 · La mejor línea

¿Cómo obtenemos la mejor línea?

Trazamos una línea y observamos los puntos más cercanos a ella. Desde esos puntos trazamos líneas que lleguen a la principal: la mejor línea es la que deja la máxima separación en ambos lados.

5 · Datos traslapados

Cuando los datos se mezclan: el parámetro C

Si la información está traslapada (mezclada), ninguna línea es perfecta: por más hiperplanos que traces, siempre clasificarás mal algún dato.

Para eso está el parámetro C: ajusta el hiperplano para separar los datos de la mejor manera. El modelo puede quedar medio raro, pero hace el trabajo. C es ajustable: hay que buscar su mejor valor.

6 · Ejemplo real

¿Quién es apto para un préstamo?

Un banco decide si aprueba una tarjeta de crédito: ▲ aprobado, ■ rechazado. X es el ingreso y Y la deuda (en miles).

Aprobado Rechazado Hiperplano Margen 
from sklearn.svm import SVC

# 1. Datos con su clase
X = [[45, 5], [38, 10], ...]  # ingreso, deuda
y = [1, 1, ..., 0, 0]         # 1 = aprobado

# 2. El modelo: línea recta y parámetro C
modelo = SVC(kernel="linear", C=1)

# 3. Entrenar: margen máximo
modelo.fit(X, y)

# 4. Clasificar un dato nuevo
modelo.predict([[25, 10]])           # [1]
modelo.decision_function([[25, 10]]) # [0.44]
  1. Datos: X son las coordenadas (ingreso, deuda) y y la clase. Conocemos las clases: aprendizaje supervisado.
  2. Modelo: kernel="linear" es una línea recta y C=1, el parámetro C.
  3. Entrenar (fit): busca la línea con el margen máximo.
  4. Clasificar (predict): de qué lado cae el dato nuevo, 1 o 0.
  5. Distancia (decision_function): qué tan lejos del hiperplano cae. Si es menos de 1, está dentro del margen y la decisión es dudosa.
Conclusión

En resumen

¿Para qué sirve?

Para que una computadora aprenda con ejemplos a separar dos grupos y luego decida sola a cuál va cada dato nuevo.

¿Para qué nos sirve?

Para tomar decisiones reales: quién es apto para un préstamo, quién cumple los requisitos para un medicamento o qué correos son spam.

Ventajas

  • Elige la línea más segura: la del margen máximo.
  • Solo depende de unos pocos puntos: los vectores de soporte.
  • Funciona bien aun con pocos datos.
  • Con el parámetro C se adapta a datos mezclados.

Desventajas

  • Hay que ajustar C; si te pasas, se aprende los datos de memoria.
  • Se vuelve lento con muchísimos datos.
  • Necesita ejemplos con su clase ya conocida.
